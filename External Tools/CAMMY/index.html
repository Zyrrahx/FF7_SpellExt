The file SpellExt reads. Edit it here and apply, or edit the rows.

What a camera is

Two scripts run side by side every frame: position (where the camera is) and focus (what it looks at). Jump puts it somewhere at once; glide moves it there over a number of frames; ride / follow keeps it on a moving bone. set wait + wait hold the script for that many frames while movements run. A script ends with end.

Using it in the game

Save the .txt into SpellExtConfig/cameras/ of the FF7 SpellExt mod, and name the camera in a spell or limit: camera_single = 0x190 and camera_multi = 0x190. Cameras are read at each battle's start: change the file, start a new battle, and the change is there.

Numbers

The game's own cameras are 0 to 18f (hex). Give yours 190 and up, one number per attack.

How close is the preview?

It replays the commands as decoded from the game's interpreters. Not modelled: bones other than the root (placed at the root unless you give heights), the actors' facing, flags and the facing placements (f2 / f3). The game's three variants all run; how the game picks the one shown is not known, so keep them the same. Always check a new camera in a battle.

Coordinates

x runs along the party's line, y is up and down (up is negative), z is forward and back (negative is toward the enemies for the party). A character is about 1000 tall; the face is about y -280. The game's view is narrow: keep what matters within about 15 degrees of the line of sight.
